# Tbot — 模拟交易面板 UI 设计

## 设计目标

将现有基础 Tbot 面板升级为产品级交易仪表盘，包含可视化图表、更丰富的账户指标、更清晰的持仓/订单展示，整体视觉风格与项目已有的 warm/terracotta 设计语言保持一致。

## 组件结构

### 1. Metric Cards (5张指标卡)
- 使用现有 `.tbot-card` 样式，加入 icon 装饰
- 新增：胜率 (Win Rate)、总交易数
- 数值颜色规则：正数绿色 (#4ade80)、负数红色 (#f87171)
- 盈亏卡片显示百分比变化

### 2. Equity Curve (权益曲线 SVG 图表)
- 纯 SVG 实现 (不使用第三方图表库，符合项目惯例)
- 面积图风格：渐变填充 (绿色到透明)
- 折线颜色：#4ade80 (正) 或 #f87171 (负)
- X轴：时间标签 (从 order.created_at 提取)
- Y轴：余额区间自动计算
- 响应式宽度
- 数据来源：从交易记录推算累计权益变化

### 3. Positions (持仓卡片)
- 每张卡片显示单个持仓
- 包含：币种名称、数量、均价、当前市值、浮动盈亏
- 盈亏正负颜色标识
- 卡片布局改为横向网格，自适应列数

### 4. Order History (交易记录表)
- 表头固定
- 行 hover 高亮
- 方向标签更醒目 (圆角 badge)
- 备注列限制宽度 + 省略号

### 5. States (状态处理)
- **Loading**: 骨架屏动画 (skeleton cards + shimmer)
- **Empty**: 插画风格空状态 (纯 CSS 图标)
- **Error**: 错误提示条带重试按钮
- **Login Required**: 居中提示

## 视觉风格

- **颜色**:
  - 卡片背景: `color-mix(in srgb, var(--bg-toggle-active) 42%, var(--bg-surface))`
  - 卡片边框: `1px solid var(--border-soft)`
  - 正值: `#4ade80` (绿色)
  - 负值: `#f87171` (红色)
  - 强调色: `var(--accent)` (项目 terracotta 色 #c96442 / #d97757)
- **圆角**: `14px` (与项目其他面板一致)
- **字体**: 数值使用 Georgia/serif (与项目数值展示一致)
- **间距**: `16px-24px` 标准间距

## 数据依赖

### 现有 API (`GET /tbot/data`)
```json
{
  "account": { "balance_usdt": 9995.73, "total_pnl": -4.27, "position_count": 1 },
  "positions": [{ "asset_symbol": "SOL", "quantity": 0.05, "entry_price": 85.34, "current_value_usdt": 4.27 }],
  "orders": [{ "id": 1, "asset_symbol": "SOL", "side": "buy", "quantity": 0.1, "price": 85.34, "total_usdt": 8.53, "reasoning": "信号", "created_at": "2024-01-15T12:20:00" }]
}
```

### 前端计算字段
- **Win Rate**: `胜率 = 盈利交易数 / 总交易数 × 100` (从 orders 计算: buy 后对应 sell 有正收益则视为盈利)
- **Total Trades**: `orders.length`
- **Equity Curve**: 从 orders 按时间顺序累计 PnL 推演
- **Position P&L**: `current_value_usdt - (entry_price × quantity)`

## 响应式

- ≥1200px: 5 列指标卡，持仓 3 列网格
- 900-1200px: 3 列指标卡，持仓 2 列网格
- <900px: 2 列指标卡，持仓 1 列网格
- 图表自动适应容器宽度
